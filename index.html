HORCRUX

Generalizable Feed-Forward 3D Hand-Object Reconstruction with Coarse-to-Fine Contact Estimation

Seonghwan ParkYong-Hoon KwonMin-Gyu Park

Korea Electronics Technology Institute (KETI)

Paper Code soon BibTeX

TL;DR. HORCRUX is a unified feed-forward transformer that reconstructs one or two hands and the held object from a single image and estimates their contact. Reasoning jointly over frozen foundation features, it generalizes to unseen objects with given or image-reconstructed meshes. Coarse-to-fine estimation resolves this contact over finer hand regions using the reconstructed geometry.

Method

A unified transformer with coarse-to-fine contact estimation

1

Joint reasoning over foundation features

Frozen foundation encoders tokenize the image, each hand crop, and the object mesh. The object is encoded from its geometry, so the model is not tied to its training objects. A shared transformer then reasons jointly over these tokens to keep the hands and the object aligned.

Coarse-to-fine contact estimation

A coarse head uses latent features to predict which joints touch the object without inheriting reconstruction errors. A fine head then localizes this contact on finer hand regions from their distances to the reconstructed object, separating the palm side of each finger from its back.

Approximate object meshes

Since HORCRUX encodes the object from its geometry, it can take a mesh that SAM 3D reconstructs from the input image in place of a scanned one. Although the two meshes differ in shape, the predicted poses nearly coincide.
